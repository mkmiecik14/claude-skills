## Writing a skill

- Every skill is a folder under `skills/` containing a `SKILL.md`.
- The `description` above decides when Claude uses the skill, so say what it does *and* when to use it.
- Supporting files (scripts, templates, reference docs) can sit next to `SKILL.md` and be referenced from it.
